前两天把博客搭起来的时候，选了个偏纸张质感的暖白色。

当时觉得挺典雅，但实际在电脑上看久了，总觉得太单薄，字和背景平铺在一起，两边空荡荡的，越看越像打印出来的 Word 文档。

后来想了想，我平时白天写代码、晚上排障，眼睛盯得最多的其实就是深蓝黑底色的终端。既然是自己的地方，折腾那么多花哨的杂志排版干嘛，不如直接照着自己终端的配色来。

---

## 怎么折腾的

改的过程没用什么现成的 UI 组件库，就纯手写了一套 CSS 变量：

1. **底色和高光**：背景直接用了 GitHub Dark 那种很深的碳蓝黑，配上亮蓝和琥珀黄的高光，看起来跟平时开着的终端窗口差不多。
2. **加了目录和代码复制**：之前看长文章一滑到底很难受，现在在宽屏右边加了个随滚动高亮的目录（TOC）；代码块右上角加了个一键复制，省得以后自己查配置还要手动全选。
3. **背景网格**：用 CSS 渐变画了点阵网格，没加载任何外部图片，加载速度完全没受影响。

技术选型还是用的 Astro 7 纯静态编译：

```ts
// 依然是纯静态，零客户端框架
export default defineConfig({
  site: 'https://huaaa3188.github.io',
  base: '/lucid-hubble',
  output: 'static',
});
```
